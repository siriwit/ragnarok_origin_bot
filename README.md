# ragnarok_origin_bot

## Create Virtual ENV
Run this commands:
```
python -m venv jj
jj/Scripts/activate
.\install.bat
```

## Install app to help convert image to text
install https://github.com/UB-Mannheim/tesseract/wiki

## Emulator Settings
Use LDPlayer, configure setting like below
- Tablet 1600x900

## Game Settings
- Graphic Med
- Framerate 60 FPS

## Map hotkey in LDPlayer
- H is daily
- F is Event
- G is guild
- M is Map
- T is Transform to Doram
- Enter is chat

## Bot.ini
Update LDPlayer Window Name
